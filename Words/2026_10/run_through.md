# run through

`/rʌn θruː/` · phr. · #六级

释义：贯穿；快速浏览；排练

例句：The argument that runs through these very different books is that influencers have changed the rhythm of our culture, as well as who in society holds power.
译文：贯穿这些迥异书籍的论点是：网红改变了我们文化的节奏，也改变了社会中谁掌握权力。

词形变化：
- runs through (phr.)：贯穿；快速浏览
- ran through (phr.)：贯穿；排练（过去式）
- running through (phr.)：贯穿；排练（现在分词）

用法：
- run through sth：贯穿；快速过一遍
  例：A common theme runs through all the stories.（所有故事都贯穿着一个共同主题。）
- a theme runs through：某主题贯穿…
  例：The idea of freedom runs through the novel.（自由这一理念贯穿整部小说。）

词根词缀：run（跑）+ through（穿过）

记忆锚点：从开头穿到结尾 → 贯穿
