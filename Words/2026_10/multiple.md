# multiple

`/ˈmʌltɪpl/` · adj. · #六级

释义：多个的；多种的；多重的

例句：It can offer multiple language support.
译文：它可以提供多种语言支持。

用法：
- multiple + 复数名词：多个…；多种…
  例：The app supports multiple languages.（这款应用支持多种语言。）
- multiple times：多次
  例：He checked the result multiple times.（他多次检查结果。）

词根词缀：multi-（多）+ -ple（折叠、倍数）→ 多重的

记忆锚点：一层又一层 → 多个、多重
