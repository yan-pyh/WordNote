# embed

`/ɪmˈbed/` · v. · #六级

释义：嵌入；使深植；深植于

例句：For a long time there has been this culturally embedded perception that if you go to law school, it will be worth the money.
译文：长期以来，人们有一种根深蒂固的文化观念：如果去读法学院，这笔钱就花得值。

词形变化：
- embed (v.)：嵌入；使深植
- embedded (adj./v.)：嵌入的；根深蒂固的
- embedding (n./v.)：嵌入；根植

用法：
- be embedded in：深植于；嵌入…中
  例：The values are embedded in the culture.（这些价值观深植于文化中。）
- embedded system：嵌入式系统
  例：The device runs an embedded system.（该设备运行嵌入式系统。）

词根词缀：em-（进入）+ bed（床、底层）→ 放入底层 → 嵌入

记忆锚点：像埋进地里一样固定下来 → 深植
