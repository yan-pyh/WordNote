# alternate

`/ˈɔːltəneɪt/` · v./adj. · #六级

释义：交替；轮流；交替的

例句：All chargers take electricity from the grid, which uses an alternating current (AC).
译文：所有充电器都从电网取电，而电网使用交流电。

词形变化：
- alternate (v./adj.)：交替；交替的
- alternating (adj./v.)：交替的；交流的
- alternated (v.)：交替（过去式）
- alternation (n.)：交替；轮流

用法：
- alternating current：交流电
  例：Most household devices run on alternating current.（大多数家用设备使用交流电。）
- alternate between：在…之间交替
  例：The weather alternates between sun and rain.（天气在晴天和雨天之间交替。）

词根词缀：altern（轮流、其他）+ -ate（使）→ 交替

记忆锚点：一上一下轮流来 → 交替
