# common

`/ˈkɒmən/` · adj. · #六级

释义：常见的；普通的；共同的

例句：Electric vehicles (EVs) are becoming commoner.
译文：电动汽车正变得越来越常见。

词形变化：
- common (adj.)：常见的；共同的
- commoner (adj./n.)：更常见的；平民
- commonest (adj.)：最常见的
- commonly (adv.)：通常；普遍地

用法：
- common sense：常识
  例：It is common sense to wear a seat belt.（系安全带是常识。）
- common practice：常见做法
  例：Remote work is now common practice.（远程办公如今是常见做法。）

词根词缀：拉丁语 communis（共同的）

记忆锚点：大家都共有 → 常见、共同
