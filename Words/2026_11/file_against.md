# file against

`/faɪl əˈɡenst/` · phr. · #六级

释义：对…提起诉讼；针对…提交文件

例句：In recent months, class-action lawsuits have been filed against more than a dozen law schools, charging that students were deceived into enrolling by postgraduate employment figures that were vastly, and falsely, inflated.
译文：近几个月来，超过十二所法学院遭到集体诉讼，指控它们用被大幅夸大且虚假的研究生就业数据诱骗学生入学。

词形变化：
- file against (phr.)：对…提起诉讼
- filed against (phr.)：对…提起诉讼（过去式/过去分词）
- filing against (phr.)：正在对…提起诉讼

用法：
- file a lawsuit against：对…提起诉讼
  例：They filed a lawsuit against the school.（他们对这所学校提起诉讼。）
- file charges against：对…提出指控
  例：Prosecutors filed charges against him.（检察官对他提出指控。）

词根词缀：file（提交）+ against（针对）

记忆锚点：把正式文件递交到针对某方的案件中 → 起诉
