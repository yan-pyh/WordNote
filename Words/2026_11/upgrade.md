# upgrade

`/ˌʌpˈɡreɪd/` · v./n. · #六级

释义：升级；提升；改善

例句：Safety systems in vehicles, such as automated circuit breakers which isolate the battery in the event of a crash, also need to be upgraded.
译文：车辆中的安全系统，例如在发生碰撞时隔离电池的自动断路器，也需要升级。

词形变化：
- upgrade (v./n.)：升级；提升
- upgrades (v./n.)：升级（第三人称单数/复数）
- upgraded (v./adj.)：升级；升级过的
- upgrading (v.)：升级（现在分词）

用法：
- upgrade a system：升级系统
  例：We need to upgrade the safety system.（我们需要升级安全系统。）
- upgrade to：升级到
  例：Users can upgrade to the premium version.（用户可以升级到高级版。）

词根词缀：up（向上）+ grade（等级）→ 升到更高等级

记忆锚点：从低等级升到高等级 → 升级
