# use

`/juːs/` · n./v. · #六级

释义：使用；用途；利用；（usage）使用；用法

例句：The usage of the new Google Earth Engine.
译文：使用新的谷歌地球引擎。

词形变化：
- use (n./v.)：使用；用途
- usage (n.)：使用；用法
- used (adj./v.)：使用过的；使用
- useful (adj.)：有用的

用法：
- the use of：…的使用
  例：The use of sensors improved the data.（传感器的使用改善了数据。）
- usage rate：使用率
  例：The app has a high usage rate.（这款应用使用率很高。）

词根词缀：拉丁语 uti（使用）

记忆锚点：把工具拿来发挥作用 → 使用
