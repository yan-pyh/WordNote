# dynamic

`/daɪˈnæmɪk/` · adj./n. · #六级

释义：动态的；有活力的；动态；动力

例句：They can display real-time dynamics of pollutants on the website.
译文：它们可以在网站上展示污染物的实时动态。

词形变化：
- dynamic (adj./n.)：动态的；动力
- dynamics (n.)：动态；动力学
- dynamically (adv.)：动态地

用法：
- real-time dynamics：实时动态
  例：The map shows the real-time dynamics of traffic.（地图显示交通的实时动态。）
- a dynamic process：动态过程
  例：Air quality is a dynamic process.（空气质量是一个动态过程。）

词根词缀：dynam（力量）+ -ic → 有力量推动变化的

记忆锚点：不断变化、不断推动 → 动态的
