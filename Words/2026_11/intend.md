# intend

`/ɪnˈtend/` · v. · #六级

释义：打算；意图；旨在

例句：Those algorithms are intended to produce a system reliable enough for a car to drive itself.
译文：这些算法旨在打造一个足够可靠、能让汽车自动驾驶的系统。

词形变化：
- intend (v.)：打算；旨在
- intends (v.)：打算（第三人称单数）
- intended (v./adj.)：打算；预期的
- intending (v.)：打算（现在分词）
- intention (n.)：意图；打算

用法：
- be intended to do：旨在做…
  例：The rule is intended to improve safety.（这项规定旨在提高安全性。）
- intend to do：打算做…
  例：We intend to finish the project this week.（我们打算本周完成这个项目。）

词根词缀：in-（朝向）+ tend（伸展）→ 心思伸向某目标 → 打算

记忆锚点：心里已经朝某个目标伸过去 → 打算
