# lizard

`/ˈlɪzəd/` · n. · #六级

释义：蜥蜴

例句：What can we learn about the lizard struck by Caribbean hurricanes?
译文：关于那只遭遇加勒比飓风的蜥蜴，我们能了解到什么？

词形变化：
- lizard (n.)：蜥蜴
- lizards (n.)：蜥蜴（复数）

用法：
- a lizard：一只蜥蜴
  例：A small lizard ran across the rock.（一只小蜥蜴跑过岩石。）
- lizard species：蜥蜴物种
  例：The island is home to several lizard species.（这座岛上有好几种蜥蜴。）

词根词缀：源自拉丁语 lacerta（蜥蜴）

记忆锚点：有鳞片和长尾的爬行动物 → 蜥蜴
